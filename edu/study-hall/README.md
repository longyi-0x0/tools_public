# 自习点名（study-hall）

自习的点名工具。老师建班、导入花名册，开始自习后逐个点学生，点过的就是到了；
自习时间里谁临时离开就点一下开始计时，超过阈值转红并出声提醒。

## 两层

```text
班级列表  →  自习蒙版  ⇄  待机蒙版
       ↑ 卡上按「开始自习」进，按「收起」回
```

**班级列表**：一张卡一个班，卡上说的是「这个班是什么」，卡底那颗是「拿它开始干活」——

| 位置 | 内容 |
| --- | --- |
| 卡左上 | 班级名 · 多少人、超时阈值、主题；有自习在跑时底下多一颗「自习中 00:12:33」跟着走 |
| 卡右上 | 自习记录 · 设置（都是翻资料，挨着放） |
| 卡底 | 一整行都是**开始自习**（有在跑的就写「继续自习」）。不画分隔线、不铺底色 —— 一条线横在那儿像把它切成另一块，看着像页脚 |
| 页头 | 多选 · 从文件恢复一个班 · **新建班级**（实心的，摆最右） |

导出与删除都在「设置」里：导出全班 xlsx 跟名册放在一块，**删除这个班**在设置的
最后一行（画一条线隔开）—— 那一手不能撤回，所以问一句才动手。导出的文件名带日期，
同一天的两次导出不会互相盖。

页头那一排里实心的永远是「新建班级」，摆在最右边 —— 一排钮里最边上的一颗最好按，
也不会跟旁边混起来。

**自习记录**是一张表（各班卡右上角、自习蒙版顶栏都能开）：每场一行，开始、结束、
自习时长、已到、离开人次、超时几人；超时的格子标红，没有超时的写「—」。底下一句
汇总（共几场、自习合计、离开人次，有超时的话再点一句「有超时 N 场」）。

要一次收拾好几个班，按页头的**多选**：

- 卡片变成勾选项（勾选框在名字左边，选中的卡蓝框加淡蓝底），整张卡点哪儿都算勾/取消，
  空格和回车也行 —— 这时候卡上的「自习记录」「设置」「开始自习」都让位了，
  因为按卡片在多选态下是「勾选」而不是那些意思。
- 页头换成「已选 N / M · 全选/取消全选 · 导出选中 · 删除选中 · 退出多选」，
  一个都没勾时导出与删除压暗按不动。
- **导出选中**：每个班一份 xlsx（还是那七张表），一起装进一个 zip 下载。
  不连着触发好几次下载 —— 浏览器会问「是否允许下载多个文件」，老师多半选否。
- **删除选中**：问一句，名单超过三个就说「等 N 个班」；**其中有班正上着自习会单独点出来**
  （那一场也一起删）。删完给一句提示。

退出按钮叫「退出多选」而不是「取消」：旁边紧挨着「取消全选」，两颗都以取消开头容易按错。

**自习蒙版**：**一次自习就是盖住整屏的这一块**。点名、四色、计时、统计、花名册都在
这里。右上角「收起」把它收下来、自习继续跑，卡片上那颗钮随即变成「继续自习」；按
「结束自习」这一场定格，蒙版留着不自动收——下课时老师正要念这一场的账，收掉就看不见了，
要走自己按「收起」。

蒙版上的按钮分三档，越往下越少用：主行动（开始点名 / 结束点名 / 结束自习）是实心的
一颗；暂停、重开是描边的普通钮；「结束并重开」和「本场静音」折在一道细分隔线下面，
字号也小一档。中间那行字（`data-hint`）永远说清「现在按哪一颗、按了会怎样」——

```text
准备    按「开始点名」，然后逐个点花名册上到了的同学。
点名中  点名中：还有 3 人没点到（蓝色）。点错了再点一下可以退回。
自习中  自习中：蓝色 2 人未到（迟到的人点一下就变灰）。有人临时离开，点一下他开始计时。
已暂停  已暂停：自习时间停在 00:12:30，外面的人也一起停表。按「继续自习」接着走。
```

**本场静音**只作用这一场：按了就只留画面上的红，不再出声，进下一场自动复位。

**待机蒙版**：自习中**30 秒**没人碰屏幕就换成这一块 —— 中间一个大钟，底下「谁还在
外面」。**任何操作都重新计时**（点一下、动一下鼠标、滚一下轮、敲一下键都算），所以
它只会在真的没人时出现。点哪儿都回到自习看板；点某一张卡片直接把那个人记成归来。
阈值按班设置（15 秒 / 30 秒 / 1 分钟 / 2 分钟 / 5 分钟 / 不切），默认 30 秒，随整班 xlsx 一起
导出导入。

花名册在自习蒙版里看；平时要看名字，「设置」里列出全班。花名册进了自习就是四色的
（没到 / 到了 / 离开），列表这一层不显示这些 —— 四色只在一次自习里才有意义。

四色都配了**图例**（四个小色块连着词），挂在自习看板上，第一回来的人也看得懂颜色。
格子第二行平时只留座位号，学号与姓名退到悬停提示里 —— 教室里认得的是人，不是学号。

按「开始自习」时会顺手向浏览器要一次全屏：教室前面那块屏不该留着地址栏。Esc 退出
全屏不影响蒙版；蒙版顶栏那颗 ⛶ 随时开关（班级列表页没有这一颗 —— 那一页不在教室前面用）。刷新或崩了重开时，**扫一遍有没有还在跑的一场**，
有就直接盖上蒙版接着用（不记「上次打开的班」—— 上次打开的可能是别的班）。

键盘也能走：**Esc** 关掉当前浮层，多选态下退回班级列表。打开浮层时焦点会自己进去
（备注落在「补充说明」那一格，设置落在班级名上）—— 键盘老师按下的那一刻焦点本来在
触发它的钮上，浮层一出来整棵树重画、焦点掉回页首，不接管的话按 Tab 得从头走一圈。
只做「进来」不做「出去」：关闭时那颗钮已经是新节点了，硬要还原得给每颗钮编号，不值当。

浮层里的第一颗钮是「✕」，所以焦点不往一排按钮上落 —— 不然顺手一个回车就把刚打开的
窗又关了。里头一个输入控件都没有时（比如自习记录）焦点落在浮层本身，既算「进来了」，
回车也不会误触任何一颗钮。

## 四色

颜色是自习蒙版的主角，语义只有一句话：**蓝是没到，灰是到了**；黄与红是「到了又离开」
的两个档。

| 颜色 | 状态 | 什么时候出现 |
| --- | --- | --- |
| 蓝 | 没到 | 开始自习后全班默认。点名阶段没点到的就一直是蓝，不用另作标记 —— 点名结束后剩下的蓝就是缺席 |
| 灰 | 到了 | 点一下变灰。点是选择不是加算，再点一下退回蓝 |
| 黄 | 离开中 | 自习时间里点一个灰的，记一次临时离开并开始计时 |
| 红 | 超时未归 | 离开超过阈值（按班设置）—— 暂停的那几段不算。转红的那一刻出声提醒，之后每隔一个补响间隔再响一次，直到点回来 |

## 一次自习

```text
开始自习 → 开始点名 → 结束点名 → 自习中 → 结束自习
准备        点名中                  自习中     已结束
```

- **准备**：全班蓝。老师按「开始点名」。这时候点名字不算数（会顶一句「先按开始点名」）——
  格子长得像按钮，点下去没反应会被当成坏了。
- **点名中**：逐个点，点到变灰。可以中途点回来改错。剩下的蓝就是没来。
  人多时按**「剩下都到」**：还没点的都算到了，再点回那几个没来的（这时点他就是退回蓝）。
  一个班几十号人，绝大多数都在座位上，这样只用点一两下。这一相里这两颗钮的次序是
  「剩下都到」在前、「结束点名，进入自习」（蓝的）在最后 —— 一排钮里最边上的一颗最好按，
  而这一相更常按的是前者。
- **自习中**：正式自习时间。**到了的排前面，没到的沉到最后另起一块**，中间一条「没到 N 人」
  的分界；迟到的人点一下变灰就归队回到前面。点名中不排 —— 那时老师正顺着名册逐个点，
  格子一挪就会点错人；待机蒙版与导出的明细都另按名册顺序走，排布只管看板上的显示。
- **已结束**：这一场定格，只读（格子里的计时也停在下课那一刻，不会再往上走；点格子会
  顶一句「要改状态先按再开一场」）。蒙版
  顶上换成**本场小结**：起止时刻、自习时长、暂停、应到 / 到了 / 没到 / 离开人次与合计、
  超时几人，再列出离开最久的四个（超时的标红，带次数与备注）。要接着来一场按「再开一
  场自习」，要回班级列表按「收起」。

过程中的任何一步都落盘，刷新或关掉浏览器再打开，回来接着这一相继续 —— **有一场还没
结束就直接盖上自习蒙版**，不必自己再进一次。

## 自习里能做的三件事

上课时什么情况都能遇到，所以除了往下走，还给了两手：

| 动作 | 做什么 | 什么时候能用 |
| --- | --- | --- |
| **暂停自习** | 自习时间停住；**外面的人也一起停表**（不然暂停二十分钟再回来，谁都变成超时了）。按「继续自习」接着走 | 自习中 |
| **结束并重开** | 结束这一场，另开一场（会先问一句）。旧的那一场留在记录里，不删 | 准备 / 点名 / 自习 |
| **结束自习** | 这一场定格，留在小结那一屏 | 点名 / 自习 |

暂停期间：时钟压暗并挂一颗「已暂停」；不响超时铃；不切待机蒙版（那时什么都没在计时，
屏幕上留着「已暂停」比换成大钟有用）。正暂停着按「结束自习」会把那一段合上，不会多算。

## 看板上有什么

**自习时间**是这一屏最大的字：从**结束点名**那一刻算起（点名一结束就是正式的自习
时间），一律写成 `时:分:秒`，小时位一直留着 —— 大屏上的数字宽度得稳，走到一小时
不能忽然跳一下。还没进自习时它是 00:00:00 且颜色沉下去；暂停时停住并压暗；结束自习
后定格不动。

旁边一排统计：应到、已到、没到、离开中、超时、离开人次（准备阶段「没到」写作
「未点」—— 那时还没点完，说「没到」是冤枉人）。「已到」把临时离开的人算在
内（他们到了，只是这会儿不在座位上），所以「离开中」与「超时」是「已到」的子集；
「没到」加「已到」等于应到。「离开中」与「超时」大于 0 时数字点亮。

格子的高度按**最坏情况（三行：名字 + 原因 + 计时）**算出来，三套主题各按自己的字号定：
童趣 101px、标准 87px、简洁 74px。定死一个值不行 —— 原来写死的 74px 只够两行，有人离开时
多出来的那行会溢出格子，上下都被相邻两行的格子盖住，名字和计时看着就像被裁了。按三行都放
得下还有个好处：谁离开、谁回来都不会让格子变高变矮，一整屏的排布不跟着跳。

人一离开，格子第二行就换成离开的原因（没填备注的写「离开中」）；点了已到的人，
浮层里除了「记离开」还有一条「他没到」—— 点错了能当场退回蓝，不用先记一次离开再改。

## 临时离开的备注

点一个人变黄之前会问一句备注，可以一条都不填 —— 不填就是纯计时。常用备注在
「班级设置」里维护（一行一条），点的时候挑一条，还能再补一句话。

补的那句话支持语音输入：走浏览器原生的语音识别（`zh-CN`）。**这是可选增强** ——
多数实现要把音频送到厂商服务器，国内网络下常常起不来；不可用时按钮会置灰并说明
原因，备注照样能手打或挑模板。

## 导入花名册

**看内容，不看扩展名。** 老师手上的名单来自各处，名字常常不作数，所以按开头几个字节与
文本长相认：

| 拿到的文件 | 实际是什么 | 认不认 |
| --- | --- | --- |
| `.xlsx` | ZIP（OOXML） | 认 |
| `.xls` | OLE2 复合文档 + BIFF8（Excel 97-2003、WPS） | 认 |
| `.xls` 但其实是 HTML 表 | 教务系统「导出 Excel」最常见的产物 | 认 |
| `.xls` 但其实是 XML 表格 | Excel 的 XML Spreadsheet 2003 | 认 |
| 别的 | —— | 报错说明，不猜 |

编码按文件自己声明的解（教务系统的导出常是 GBK 系）；声明与内容不符时（少数导出会
把 UTF-8 存成 gb2312 的名字）以能被严格 UTF-8 解通为准。

认列靠首行文字：有一列写着「姓名」或「名字」，学号与座位列可选。没有表头时退回
「第一列学号、第二列姓名」。多张表时先找叫「名册」的，没有就逐张试到读出学生为止 ——
教务系统的导出常把标题、说明各占一张表。

导出的一直是 `.xlsx`：Excel、WPS、Numbers 都打得开，不必再写一套二进制写出。
「从文件恢复一个班」也只认本工具导出的 `.xlsx`（那是整班的数据，不是花名册）。

## 一个班一个文件

导出的是**这个班的全部**：班级设置（含超时阈值、出声开关、补响间隔、待机蒙版 —— 它们按班
为单位）、常用备注、名册、每一场记录、每一场的点名明细、离开明细与暂停明细，共七张表：

| 表 | 内容 |
| --- | --- |
| 班级 | 名称、主题、超时阈值、出声开关、补响间隔、待机蒙版、导出时间 |
| 备注模板 | 序号与文本 |
| 名册 | 学号、姓名、座位 |
| 会话 | 每场一行：各相时刻、应到 / 已到 / 没到 / 离开人次 / 累计离开 / 暂停次数与时长 |
| 点名明细 | 每场 × 每人一行：是否点到 |
| 离开明细 | 每人每次一行：离开时刻、归来时刻、时长、是否超时、备注 |
| 暂停明细 | 每次暂停一行：暂停时刻、继续时刻、时长 |

时间在表里写成 Excel 日期而不是文本，老师拿到文件能直接排序与筛。导入时按同样的表
重建；**检测到同名班级会问一句「覆盖还是另建副本」**，不会闷声盖掉。

## 主题

三套：童趣（小学）、简洁（高中）、标准。按班设置 —— 同一个工具给不同的班用，
格子的大小与密度跟着换，四色的语义不动。

## 数据在哪

只在这台机器的这个浏览器里，**换浏览器或清站点数据就没了** —— 这是本工具的既定
形态。数据放在 IndexedDB；启动时向 `navigator.storage.persist()` 申请持久化配额，
避免 Safari 的七天不活跃驱逐。申请被拒不影响使用，只是那份数据可能被系统回收。

要换机器或留档，用「导出全班 xlsx」。

## 怎么跑

工具页是**静态页**：不经过打包器，也不依赖工具箱外壳的样式。可以直接把它当普通
静态站点打开：

```bash
# 仓库根
python3 -m http.server 5210 --directory src/tcb/toolbox_service/tool_sources/tools_public/edu/study-hall/site
```

浏览器打开 <http://127.0.0.1:5210/>。要语音输入得走 HTTPS（`localhost` 例外）。

发布走工具箱那一套：本目录的 `toolbox.json` 声明为一个 `kind: "h5"` 的工具，
`site/` 下的文件由 `toolbox_service` 发布，工具箱壳从发布地址装载。清单契约见主仓的
`docs/containers/toolbox_app/附录/01-工具清单.md`。

## 目录

```text
site/
├── index.html          页面骨架，只挂样式与入口
├── styles.css          四色、三套主题、看板与浮层的样式
└── js/
    ├── app.js          界面与装配：两层视图（班级列表 / 蒙版）、一个状态、走秒定点更新
    ├── domain.js       状态机与四色推导、统计、该响哪几条、老数据补齐。纯函数，不认识浏览器
    ├── store.js        IndexedDB 三个 store（classes / sessions / settings）
    ├── readSheets.js   按内容读表格（不看扩展名），花名册走这里
    ├── klassFile.js    一个班 ↔ 一份 xlsx
    ├── xlsx.js         最小 xlsx 读写（自己写的 ZIP + 够用的 OOXML）
    ├── cfb.js          OLE2 复合文档的读取（.xls 是个小文件系统）
    ├── biff.js         BIFF8 的读取（Excel 97-2003 的单元格）
    ├── textTable.js    HTML 表与 XML Spreadsheet 2003
    ├── sound.js        超时提示音，WebAudio 现场合成
    └── speech.js       备注的语音输入
```

`xlsx.js` 是自己写的：工具页不经打包器，拿不到 npm 上的表格库。压缩走浏览器的
`CompressionStream('deflate-raw')`，不支持时退回不压缩的 stored。批量导出复用的也是
它 —— 一个工作簿本来就是 ZIP，拿同一套打包代码把几份 xlsx 装成一个归档即可。

`cfb.js` / `biff.js` / `textTable.js` 同理是为读 `.xls` 写的：前者把复合文档当成
一个很小的文件系统把 `Workbook` 流取出来，中间那层按 BIFF8 的记录切单元格，后者对付
被存成 `.xls` 的网页表格 —— 三者都不依赖浏览器 API，验的时候能在 Node 里跑，
拿 `xlrd` 这类只认 `.xls` 的外部库当裁判逐格对。
