# 自习点名（study-hall）

晚托与自习的点名工具。老师建班、导入花名册，开始记录后逐个点学生，点过的就是到了；
自习时间里谁临时离开就点一下开始计时，超过阈值转红并出声提醒。

## 四色

颜色是这一屏的主角，语义只有一句话：**蓝是没到，灰是到了**；黄与红是「到了又离开」
的两个档。

| 颜色 | 状态 | 什么时候出现 |
| --- | --- | --- |
| 蓝 | 没到 | 开始记录后全班默认。点名阶段没点到的就一直是蓝，不用另作标记 —— 点名结束后剩下的蓝就是缺席 |
| 灰 | 到了 | 点一下变灰。点是选择不是加算，再点一下退回蓝 |
| 黄 | 离开中 | 自习时间里点一个灰的，记一次临时离开并开始计时 |
| 红 | 超时未归 | 离开超过阈值（按班设置）。转红的那一刻出声提醒，之后每隔一个补响间隔再响一次，直到点回来 |

## 一次记录

```text
开始记录 → 开始点名 → 结束点名 → 自习中 → 结束自习
准备        点名中                  自习中     已结束
```

- **准备**：全班蓝。老师按「开始点名」。
- **点名中**：逐个点，点到变灰。可以中途点回来改错。剩下的蓝就是没来。
- **自习中**：正式自习时间。迟到的人点一下照样变灰；已到的人点一下记离开。
- **已结束**：这一场定格，只读。可以「再开一场」，前一场留着。

一次记录过程中的任何一步都落盘，刷新页面、关掉浏览器再打开，回来接着这一相继续。

## 临时离开的备注

点一个人变黄之前会问一句备注，可以一条都不填 —— 不填就是纯计时。常用备注在
「班级设置」里维护（一行一条），点的时候挑一条，还能再补一句话。

补的那句话支持语音输入：走浏览器原生的语音识别（`zh-CN`）。**这是可选增强** ——
多数实现要把音频送到厂商服务器，国内网络下常常起不来；不可用时按钮会置灰并说明
原因，备注照样能手打或挑模板。

## 导入花名册

**看内容，不看扩展名。** 老师手上的名单来自各处，名字常常不作数，所以按开头几个字节与
文本长相认：

| 拿到的文件 | 实际是什么 | 认不认 |
| --- | --- | --- |
| `.xlsx` | ZIP（OOXML） | 认 |
| `.xls` | OLE2 复合文档 + BIFF8（Excel 97-2003、WPS） | 认 |
| `.xls` 但其实是 HTML 表 | 教务系统「导出 Excel」最常见的产物 | 认 |
| `.xls` 但其实是 XML 表格 | Excel 的 XML Spreadsheet 2003 | 认 |
| 别的 | —— | 报错说明，不猜 |

编码按文件自己声明的解（教务系统的导出常是 GBK 系）；声明与内容不符时（少数导出会
把 UTF-8 存成 gb2312 的名字）以能被严格 UTF-8 解通为准。

认列靠首行文字：有一列写着「姓名」或「名字」，学号与座位列可选。没有表头时退回
「第一列学号、第二列姓名」。多张表时先找叫「名册」的，没有就逐张试到读出学生为止 ——
教务系统的导出常把标题、说明各占一张表。

导出的一直是 `.xlsx`：Excel、WPS、Numbers 都打得开，不必再写一套二进制写出。
「导入班级文件」也只认本工具导出的 `.xlsx`（那是整班的数据，不是花名册）。

## 一个班一个文件

导出的是**这个班的全部**：班级设置（含超时阈值、出声开关、补响间隔 —— 它们按班
为单位）、常用备注、名册、每一场记录、每一场的点名明细与离开明细。六张表：

| 表 | 内容 |
| --- | --- |
| 班级 | 名称、主题、超时阈值、出声开关、补响间隔、导出时间 |
| 备注模板 | 序号与文本 |
| 名册 | 学号、姓名、座位 |
| 会话 | 每场一行：各相时刻、应到 / 已到 / 没到 / 离开人次 / 累计离开 |
| 点名明细 | 每场 × 每人一行：是否点到 |
| 离开明细 | 每人每次一行：离开时刻、归来时刻、时长、是否超时、备注 |

时间在表里写成 Excel 日期而不是文本，老师拿到文件能直接排序与筛。导入时按同样的表
重建；**检测到同名班级会问一句「覆盖还是另建副本」**，不会闷声盖掉。

## 主题

三套：童趣（小学）、标准、沉稳（高中）。按班设置 —— 同一个工具给不同的班用，
格子的大小与密度跟着换，四色的语义不动。

## 数据在哪

只在这台机器的这个浏览器里，**换浏览器或清站点数据就没了** —— 这是本工具的既定
形态。数据放在 IndexedDB；启动时向 `navigator.storage.persist()` 申请持久化配额，
避免 Safari 的七天不活跃驱逐。申请被拒不影响使用，只是那份数据可能被系统回收。

要换机器或留档，用「导出全班 xlsx」。

## 怎么跑

工具页是**静态页**：不经过打包器，也不依赖工具箱外壳的样式。可以直接把它当普通
静态站点打开：

```bash
# 仓库根
python3 -m http.server 5210 --directory src/tcb/toolbox_service/tool_sources/tools_public/edu/study-hall/site
```

浏览器打开 <http://127.0.0.1:5210/>。要语音输入得走 HTTPS（`localhost` 例外）。

发布走工具箱那一套：本目录的 `toolbox.json` 声明为一个 `kind: "h5"` 的工具，
`site/` 下的文件由 `toolbox_service` 发布，工具箱壳从发布地址装载。清单契约见主仓的
`docs/containers/toolbox_app/附录/01-工具清单.md`。

## 目录

```text
site/
├── index.html          页面骨架，只挂样式与入口
├── styles.css          四色、三套主题、看板与浮层的样式
└── js/
    ├── app.js          界面与装配：一个状态、一个整块重画、走秒定点更新
    ├── domain.js       状态机与四色推导、统计、该响哪几条。纯函数，不认识浏览器
    ├── store.js        IndexedDB 三个 store（classes / sessions / settings）
    ├── readSheets.js   按内容读表格（不看扩展名），花名册走这里
    ├── klassFile.js    一个班 ↔ 一份 xlsx
    ├── xlsx.js         最小 xlsx 读写（自己写的 ZIP + 够用的 OOXML）
    ├── cfb.js          OLE2 复合文档的读取（.xls 是个小文件系统）
    ├── biff.js         BIFF8 的读取（Excel 97-2003 的单元格）
    ├── textTable.js    HTML 表与 XML Spreadsheet 2003
    ├── sound.js        超时提示音，WebAudio 现场合成
    └── speech.js       备注的语音输入
```

`xlsx.js` 是自己写的：工具页不经打包器，拿不到 npm 上的表格库。压缩走浏览器的
`CompressionStream('deflate-raw')`，不支持时退回不压缩的 stored。

`cfb.js` / `biff.js` / `textTable.js` 同理是为读 `.xls` 写的：前者把复合文档当成
一个很小的文件系统把 `Workbook` 流取出来，中间那层按 BIFF8 的记录切单元格，后者对付
被存成 `.xls` 的网页表格 —— 三者都不依赖浏览器 API，验的时候能在 Node 里跑，
拿 `xlrd` 这类只认 `.xls` 的外部库当裁判逐格对。
