# 自习点名（study-hall）

自习的点名工具。老师建班、导入花名册，按「开始自习」就进了计时 —— **点名不是必经的
一步**，想点的时候按「点名」把没来的人挑出来；自习时间里谁临时离开就点一下，挑一条备注
开始计时 —— 每条备注有自己的颜色，填了分钟数的那几条过了就转红并出声。

界面写在两块面上，因为这块屏在两种距离上用：

- **板**（自习看板、待机屏）是教室前面那块屏，八米外看。大字、默认态安静 —— 全班在座时
  是一格格安静的描边方块，只有**没来 / 离开 / 超时**才上色，老师的眼睛直接落在需要处理的
  那几个人身上。
- **纸**（班级列表、各层浮层）是老师坐下来备课、整理资料时看的，近距离、密一些。

两块面**各有一个亮暗的值**，页头那颗钮一起换：投影上用暗（默认），白天在笔记本上备课用亮。
挑过就记住；没挑过时跟一次系统的 `prefers-color-scheme`，之后**不跟着系统变** —— 教室前面
那块屏在课中间忽然翻成亮色，比一开始就选错更糟。

两块面共用一个墨色：暗的时候它是板的底，亮的时候它是纸上主行动钮的填充 —— 主行动在两个
模式里都不占用任何语义色，按钮永远不会被误读成某个学生状态。

## 两层

```text
班级列表  →  自习看板  ⇄  待机屏
       ↑ 卡上按「开始自习」进，按「返回」回
```

**班级列表**：一张卡一个班，卡上说的是「这个班是什么」，卡底那颗是「拿它开始干活」——

| 位置 | 内容 |
| --- | --- |
| 卡左上 | 班级名 · 多少人；有自习在跑时这一行上多一段「自习中 00:12:33」跟着走 |
| 卡右上 | 记录 · 设置（都是翻资料，挨着放） |
| 卡底 | 一整行都是**开始自习**（有在跑的就写「继续自习」）。不画分隔线、不铺底色 —— 一条线横在那儿像把它切成另一块，看着像页脚 |
| 页头 | 多选 · 导入班级文件 · **新建班级**（实心的，摆最右） |

有自习在跑的那张卡，左边还有一道蓝色竖杠：一屏十几个班时，光看名字下面那行小字
认不出哪个班还在上着，一道竖杠扫一眼就见。

卡上不写「格子大小」那个选项：老师认自己的班靠名字，那是当初建班时选的，摆在卡上只是多一行字。

导出与删除都在「设置」里：导出 xlsx 跟名册放在一块，**删除这个班**在设置的最后一行
（画一条线隔开）—— 那一手不能撤回，所以问一句才动手。导出的文件名带日期，同一天的
两次导出不会互相盖。

页头那一排里实心的永远是「新建班级」，摆在最右边 —— 一排钮里最边上的一颗最好按，
也不会跟旁边混起来。

一个班都没有时那一片空态只写一句「导入一份花名册就能开始上课」，加一颗「新建班级」——
第一次打开的老师要的是动手的那一下，不是先读完五条步骤。

**记录**是一张表（各班卡右上角、自习看板顶栏都能开）：每场一行，开始、结束、时长、
在座、离开人次、超时几人；超时的格子标红，没有超时的写「—」。底下一句汇总（共几场、
自习合计、离开人次，有超时的话再点一句「有超时 N 场」）。

要一次收拾好几个班，按页头的**多选**：

- 卡片变成勾选项（勾选框在名字左边，选中的卡蓝框加淡蓝底），整张卡点哪儿都算勾/取消，
  空格和回车也行 —— 这时候卡上的「记录」「设置」「开始自习」都让位了，
  因为按卡片在多选态下是「勾选」而不是那些意思。
- 页头换成「已选 N / M · 全选/取消全选 · 导出所选 · 删除所选 · 退出多选」，
  一个都没勾时导出与删除压暗按不动。
- **导出所选**：每个班一份 xlsx（还是那七张表），一起装进一个 zip 下载。
  不连着触发好几次下载 —— 浏览器会问「是否允许下载多个文件」，老师多半选否。
- **删除所选**：问一句，名单超过三个就说「等 N 个班」；**其中有班正上着自习会单独点出来**
  （那一场也一起删）。删完给一句提示。

退出按钮叫「退出多选」而不是「取消」：旁边紧挨着「取消全选」，两颗都以取消开头容易按错。

**自习看板**：**一次自习就是盖住整屏的这一块**。颜色、计时、统计、花名册都在
这里，点名是它上面的一层窗（见下）。顶栏「返回」把它收下来、自习继续跑，卡片上那颗
钮随即变成「继续自习」；按「结束自习」**先问一句**（这一下不可回退），确认后这一场
定格、看板直接收起回班级列表 —— 课上结束时老师要的是干净地离开这一屏，不是再看一遍
刚才那场的账。那一场的账在「记录」里，随时能翻。

看板从上到下四段：

| 位置 | 内容 |
| --- | --- |
| 顶栏 | 最左是**返回**（在班名之前：它是不在这一屏待了，与右边那排「在这一屏里做什么」不是一回事）· 然后班名与本场状态 · 右侧依次 **记录** · **亮色 / 暗色** · 全屏 |

顶栏上**不写工具名**：这一栏说的是「在哪、什么状态、能做什么」，工具名在浏览器标签上。
班级列表页那一栏更空（只有一个亮暗钮），那里的 h1 由页面上的「班级」顶着。
| 时钟带 | 左边整屏最大的那个钟；右边四个计数（在座 · 没来 · 离开 · 超时），每个数前面带自己的色点 |
| 格子 | 花名册。在座是安静的描边方块，没来是灰块，离开刷那条备注的颜色，超时是红块并呼吸 |
| 底栏 | 动作。左边「暂停自习 / 点名 / 多人离开」，右边「教室响度 / 自动待机 / 待机屏 / 静音」，最右一道竖线隔开「重新开始 / 结束自习」 |

四个计数**同时就是四色的字典**：每个数前面带自己的色点。原来另起一行的小灰字图例在
投影上读不出来，而且统计与图例说的本来就是同一件事 —— 合成一处，老师看数字的时候顺带
就把颜色认了。「应到」不用摆（在座加没来就是它），「离开人次」挪进「记录」。

动作压在屏幕下沿，是因为这块屏多半是投影或触屏：下沿是手最容易到的地方，也是眼睛顺着
格子往下走的自然落点。三档靠位置与填充分，不靠颜色分（投影偏色时颜色最不可靠）：
主行动「暂停自习 / 继续自习」是实心的粉笔白那一颗；「点名 / 多人离开」描边；
「重新开始 / 结束自习」在右边一道竖线之后 —— 它们不是「接着上课」，是「这一场到这儿为止」，
混在左边一排里手快就会按错，「结束自习」还是红的。

看板上不写「现在该按哪一颗」那行旁白：按钮的字已经说清了，而那行字每半秒重算一次，
反倒在老师正点着格子的时候动。
**点名层**是一块比寻常浮层宽得多的窗（一个班几十号人得在一屏里摆下），按名册顺序排，
里头每个名字跟看板上的格子同一套颜色语言：**到了是安静的浅底方块，没到才是灰块** ——
这一层里最要紧的是「还有哪几位没点到」，让灰的跳出来比让全班都亮着有用。

**看这一场点过名没有**：没点过（刚开自习）就全班都算「没到」（灰），老师照着名单往下点，
点到谁谁到；点过了就按这一场现在的名单摆出来，接着点、改点错的都行。点错了再点一下退回
灰，所以这一层始终是「点到谁谁到」，不必先看一眼「哪几个已经算在座了」。

左手那两颗是两种常见的整轮情况：班上只有少数没来（按**「全部算没到」**，再点回那几位），
或者一整轮点错了（按**「全部算到」**）。不叫「反选」—— 老师想的是这两件事，不是「取反」。

脚上那颗主行动写的是**「记下 N 人没来」**（一个都没点时写「全班到齐」）：它说的就是按下去
会发生什么。

每个名字右上角还有一颗**喇叭**：点一下把这个名字念出来（本机合成，不联网），教室后排
也听得见叫的是谁。喇叭不进 Tab 序列（一班几十号人，Tab 上多一倍就走不完这一趟），
鼠标与触摸直接点得到；浏览器没有合成接口时这颗钮不画。

喇叭上面是**自动点名**那一栏：按固定间隔（默认 1 秒，可改 1 / 2 / 3 / 5 / 8 秒）把名册
逐个念下去，老师只管听名字点格子。正念到的那一格外面描一圈 —— 后排听不清是谁、或者点了
「上一个 / 下一个」跳着念时，一眼能看出停在哪儿，不必去数旁边那行「第几个 / 共几个」。

一排钮从**「开始念 / 暂停念」**起 —— 接着是**「从头念」**（退回名册开头，再走就从第一个
名字起）、**「上一个」**、**「下一个」**（这三个都是立刻念那一个，间隔重新起算），右边是
间隔与「第几个 / 共几个」。**暂停与从头念是两件事**：暂停停在半路，再按接着往下走；
从头念是从第一个名字重开一遍。念到最后一名就停下并说一句「名册念完了」，不绕回去
（再绕一圈会把刚点过的名字又喊一遍），想再来一轮就按「从头念」。收窗就走人，那一趟自动停。
它**只念名字，不动名单** —— 谁到了仍由老师点。喇叭与自动点名都只出声，两件事都不碰名单。

**提示条挂在顶上**：底下是看板的动作条，提示常常正是按了那一排里某一颗之后出来的 ——
收在底下就把它自己盖住了。提示条宽度卡在屏宽的 48% 以内，好让它待在顶栏中间那段空处，
不压到左边的班名与右边那几颗钮。

**这一层里点的只算在这一层里**：自习上什么都没变 —— 看板的格子与统计、导出的文件、
「记录」都还是开门那一刻的样子，直到按脚上那颗才一次落进去（字上带「N 人没来」，那是
按下去会记成没来的几位：这一场没点过名时就是全班人数，点一个少一个）。按它就是把这一趟摆
出来的名单整份写进这一场 —— 不想要了就右上那颗 ✕ 收窗走人（Esc 与点窗外同义），没有半截
名单留下，也不必逐个撤回。

表里每个名字的灰蓝由走秒那条路定点改，不重画整块：点一下只换那一个格子的脸，老师刚点着
的位置与键盘焦点都留着；点名层开着时看板上不画「没来 N 人」那条分界 —— 那会儿格子按名册
冻着，这条线指的「后面那一拨」并不成立。

**静音**（底栏那颗）只作用这一场：按了就只留画面上的红，不再出声（超时本来也只对填了
分钟数的
那几条备注响），进下一场自动复位。

## 教室响度

教室有多响，是一整场自习的事，所以这一手挂在看板的底栏（与「自动待机 / 静音」同档），
**不是**待机屏上的一件东西 —— 待机屏只是它的一块显示屏。

**默认就听着**：进自习、以及刷新后接上一场在跑的自习，都自动开一次 —— 教室里有多响是这一场
的基本信息，不该要老师先想着去按一下。不想听就按底栏那颗停止，停掉之后这一场不再自己开回来
（再按一次可以重新开）。浏览器会弹一次麦克风权限，那一下老师看得见；他按了拒绝，画面上的
那行读数就一直是空的。

浮层里没有「关闭」钮：它只是一扇窗，看一眼、拧一下就完事，收窗交给右上角的 ✕、Esc 与点窗外。
脚上只留这一层唯一的那一手：开始听 / 停止听。

**读的是响度，不是录音**：每一截波形都在当场变成 0–100 的一个数就丢掉，不存、不传、
不写进任何文件，也不进导出的 xlsx。停掉、或者这一场结束（或「重新开始」）时**真的放手**
（`getUserMedia` 的轨道停掉，浏览器上那个「正在录音」的记号就灭），不是只停下读数；
进下一场也不接着听。

那个数不是校准过的分贝：**每台机器的麦克风利得都不同**，同一个教室换台电脑就是另一个数。
所以阈值是「一个班一台机器」当场调出来的。「安静」与「正常说话」正好落在 0–100 的中间，
这就是它唯一的用处 —— 纵向比较：比刚才静了还是吵了、越过那条线没有。

**阈值分两处**（与「多久不动换成待机屏」同一个规矩）：

| 在哪儿 | 管什么 | 存哪儿 |
| --- | --- | --- |
| 班级设置里那一项 | 这个班的默认 | 班级上，随整班 xlsx 一起导出导入 |
| 底栏「教室响度」浮层里那条尺 | 本场当场拧 | 只存内存，本场有效、不写回班级 |

分两处是因为这两件事不一样：换台机器、换间教室，就该回去改班级上的默认；而那会儿老师
正听着教室，拧完接着上课，不该为此进设置里翻一层。浮层里拧过之后底下会写一句
「这一场用 65（班级默认 60）」，旁边一颗「用班级默认值」能拧回去。

判定不是「读数一过线就变」：

- **连着 3 拍（300 毫秒）** 越过那条线才算「吵起来了」—— 一声关门、一下拖椅子都会把读数
  顶上去，为它们换一次脸，屏幕上就只剩闪烁。
- 要静下来得**低于那条线 5 以上、并且守满 1 秒**：在线上来回蹭的读数不该反复改判。
- 改阈值的那一刻**当场重新起判**，不拖着旧阈值立起来的那个「吵」—— 不然老师把线调高了，
  屏幕上还红着，看到的跟刚调的对不起。
- 读数是**平滑过**的（每拍往新值靠 30%），生值直接摆出来数字会一直跳。

两个地方用这个数，各用各的问法：

- **待机屏染色**（见上）按「读数离阈值多远」分五档：**绿 → 淡绿 → 中性 → 红橘 → 红**。
- **提醒**要的是「算不算吵起来了」，用上面那套带迟滞的判定：吵着**没停满 10 秒**才出一声，
  而且一次吵只响一次，静下来之后再吵才算新的一次。一次物响就出声是不行的 —— 教室里
  一声一声地响，提醒音会比教室还吵。这一声与超时那声**不一样**（那边「叮·咚·叮」一路往下，
  这边短促的两下往上），老师背对着屏幕也分得出是哪一件事。

出声的规矩与超时提醒一致：班级设置里关掉了「有人超时出声提醒」就不响，静音了也不响
（只在画面上的那行读数里点一下暖色）。

一条前提：`getUserMedia` 要求**安全上下文**（`https://` 或本机 `localhost` / `127.0.0.1`）。
教室里用内网地址（`http://192.168.x.x`）打开这一页时，浏览器不给麦克风，没有绕法 ——
与语音识别是同一条限制，所以浮层里那颗钮会压暗并说明原因。

**待机屏**：自习中**30 秒**没人碰屏幕就换成这一块：

```text
┌──────────────────────────────────────────────────────────────┐
│ 高二（3）班   2026 年 10 月 11 日 星期日                      │ 抬头贴左上
│                                                              │
│                        22:19                                 │ 顶天的大钟
│                  自习已进行 00:25:55                          │
│            在座 38 · 没来 2 · 离开 0 · 超时 0                  │ 四个计数
│                                                              │
│ ──────────────────────────────────────────────────────────── │
│ 离开中 1 人，点击名字记他归来                                  │ 只有真有人时才有这块
│ [ 杨帆 上厕所 05:12 ]                                          │
│                     点击屏幕返回看板                            │
└──────────────────────────────────────────────────────────────┘
```

班名与日期摆在**左上角一条**，不跟大钟竖着叠在中间：那一行是「这是哪个班、今天几号」的
抬头，读一眼就够，中间那块留给钟。日期带星期几（待机屏常常是老师抬头看「今天几号、周几」
的那一眼）。**没有人离开时，「谁还在外面」那一块整块不画** —— 一个空标题加一条横贯整屏的
分割线，只是把这一屏切成两半，什么也没说。

**任何操作都重新计时**（点一下、动一下鼠标、滚一下轮、敲一下键都算），所以它只会在真的
没人时出现。点哪儿都回到看板；点某一张卡片记那个人归来（**先问一句**：这一趟的时长就到
此为止，按错了得重新记一次离开、从头计时）。

想**现在就去**待机屏，按底栏那颗**「待机屏」** —— 与旁边那颗**「自动待机」**是两件事：
「自动待机」管的是「这一场要不要自己换屏」，「待机屏」是「现在就换过去」。课上常常是老师
要离开一会儿，随手把屏幕换成大钟；也常常是班设置里选了「不切」，而某一刻就是想要那块钟。
所以两颗互不影响，也不压暗。

**这一屏的底色自成一套，与亮暗无关**：

| 状态 | 底色 | 字色 |
| --- | --- | --- |
| 没在读教室响度 | 亮色模式一块干净的白 `#fff`，暗色模式一块干净的黑 `#000` | 跟着这一档的粉笔色 |
| 读着 | **一律走浅底那套**（白为主，从静到吵是绿 → 中性 → 红）+ 墨色字 | 深墨与灰 |

读着的时候连暗色模式也走浅底，是因为暗色主题下把淡绿淡暖压在深底上只会变成**一片灰**，
「偏静还是偏吵」就看不出来了。所以这一屏不跟看板共用字色 —— 它自己那一组 `--idle-*`
就为这个准备。

染的只是**底**那一层：大钟、统计、那几张「离开中」的卡片都不动 —— 卡片刷的是那条备注的
颜色（黄 / 紫 / 红……），压在浅底上本来就得看得清，字色再跟着底色走，从后排反而更难读。
读着的时候大钟底下多一行「教室 42 · 阈值 60」。

五档是一色阶，色相走一条直线：

| 档 | 什么时候 | 色 | 色相 / 明度 / 饱和度 |
| --- | --- | --- | --- |
| 静 | 读数比阈值低 20 以上 | `#d3ecdb` | 139° / 88% / 40% |
| 稍静 | 低 8 到 20 | `#e2f0e1` | 116° / 91% / 33% |
| 临界 | 在阈值上下 8 以内 | `#f0f0eb` | 60° / 93% / 14% |
| 稍吵 | 高 8 到 20 | `#f9d9cf` | 14° / 89% / 78% |
| 吵 | 高 20 以上 | `#f7b3ad` | 5° / 82% / 82% |

两头都要「一眼认得出是什么颜色」，所以不能只挪色相不动明度与饱和度 —— 红那半把明度压
下去（89% → 82%）并把饱和度提到 82%，绿那半也给足（40% / 33%）。**临界那一档几乎无色**
（14%）是故意的：颜色是「越线」的信号，贴在线上时不该已经红着，所以从「临界」到「稍吵」
是一次明显的跳（色相 60° → 14°），而不是慢慢挪。越线时那行读数的字色用深红 `#b3261e`，
不用橙 —— 橙压在红上会发浑。

**隔多久切**按班设置（15 秒 / 30 秒 / 1 分钟 / 2 分钟 / 5 分钟 / 不切），默认 30 秒，
随整班 xlsx 一起导出导入。**这一场切不切**由底栏那颗「自动待机」当场定：

- 老师正讲着一道题、或者那会儿就是要一直盯着花名册，按一下把它关掉，这一场就不再自己换屏。
- 只管这一场：只存内存，进下一场自动开回来，刷新也开回来 —— 宁可多切一次，
  也别一直不切而没人知道（与「静音」一个道理）。
- 班设置里选了「不切」的班，这颗钮压暗按不动 —— 本来就永不切，再给一个开关是假的。

花名册在自习看板里看；平时要看名字，「设置」里列出全班。花名册进了自习就是带颜色的
（在座 / 没来 / 离开），列表这一层不显示这些 —— 颜色只在一次自习里才有意义。

格子第二行平时只留座位号，学号与姓名退到悬停提示里 —— 教室里认得的是人，不是学号。
四色的意思写在**时钟带那四个数**上（每个数前面带自己的色点），不再另起一行图例。

**全屏由老师自己按**：顶栏右边那颗（班级列表页没有它 —— 那一页不在教室前面用）。按「开始
自习」**不会**自动要全屏 —— 课上常常是老师先在屏幕上把名单点一遍再上投影，或者拿投影切了
别的画面，自动抢一次全屏反而会打断他手上的事。Esc 退出全屏不影响蒙版。
刷新或崩了重开时，**扫一遍有没有还在跑的一场**，有就直接盖上蒙版接着用（不记「上次打开的
班」—— 上次打开的可能是别的班）。

键盘也能走：**Esc** 关掉当前浮层（点名层里也**只是收窗**：这一趟没按脚上那颗就不算数），
多选态下退回上一步 —— 班级列表的多选退回列表，看板上的多选退的是那几颗勾（不是这一场
自习）。打开浮层时焦点会自己进去
（备注落在「补充说明」那一格，设置落在班级名上）—— 键盘老师按下的那一刻焦点本来在
触发它的钮上，浮层一出来整棵树重画、焦点掉回页首，不接管的话按 Tab 得从头走一圈。
只做「进来」不做「出去」：关闭时那颗钮已经是新节点了，硬要还原得给每颗钮编号，不值当。

多数浮层头上第一颗钮是「✕」，所以焦点不往一排按钮上落 —— 不然顺手一个回车就把刚打开
的窗又关了。焦点落不到输入控件时，落在浮层本身（记录就是这种，点名层也一样 ——
它的 ✕ 是「这一趟不算数」，更不该让一个回车碰上）。

## 颜色

颜色是自习看板的主角。**默认态是最安静的那一个**：全班在座时是一格格透明底 + 一道描边
的方块 —— 坐在座位上是默认事实，不必点几十下，也不该让四十个高饱和色块铺满教室前面的屏。
只有例外才上色：

三个**语义色**不由老师改：

| 颜色 | 意思 | 什么时候出现 |
| --- | --- | --- |
| 描边（不上色） | 在座 | **开始自习后全班的默认** —— 安静的方块，老师的眼睛才落得到别处 |
| 灰 | 没来 | **这一场还没点过名时，点名层一开就是全班这个色**，点到的人才变蓝；点过了再开就按现在的名单摆。到没到只由点名层定 —— 看板上点他没这一手 |
| 红 | 超时未归 | 离开的时长过了**那条备注**填的分钟数 —— 暂停的那几段不算。转红的那一刻出声提醒，之后每隔一个补响间隔再响一次，直到点回来 |

离开中另有一套六色（黄、橙、绿、紫、粉、青），**按备注挑**，黄是默认：

| 备注 | 离开时刷什么色 | 什么时候转红 |
| --- | --- | --- |
| 上厕所 · 橙 · 3 分钟 | 橙 | 出去超过 3 分钟 |
| 打水 · 绿 ·（分钟数留空） | 绿 | 不转红，也不出声 —— 这条只是计个数 |
| （没挑备注） | 黄 | 不转红 |

超时**不是全班一个数**：「去办公室」要 10 分钟、「上厕所」3 分钟就够，同一个班里谁也别
拿别人的尺子量。所以时长挂在每条备注上，在「班级设置」里一条一条填。

## 一次自习

```text
开始自习 ────────────────→ 结束自习
自习中（计时在走）              已结束
   └ 点名（可选，随时开关）
```

- **自习中**：一按「开始自习」就在计时，全班默认在座。**没来的排在最后另起一块**，
  中间一条「没来 N 人」的分界；点一个灰的他归队回到前面。有人临时离开就点一下他，
  弹一句备注再开始计时；点一个离开中的人**先问一句**再记他归来 —— 那一下按错了，
  这一趟的时长就白记了，得重新记一次离开、从头计时（待机屏上那几张卡片同理）。
- **点名**（可选）：看板上的「点名」开一层盖在自习上的窗。窗里按名册顺序摆着全班，
  **这一场没点过名就全班都算「没到」**（灰块），点一下名字就是「他到了」，他当场变回浅底；
  点过了再开就按现在的名单摆。点错了再点一下退回灰。
  **这一层里点的要按脚上那颗才算数**：没按之前自习上是开门那一刻的样子，收窗走人什么也
  不会留下；重开一次是从头点一遍，没点到的会被记成没来。几十号人一次点不完也没关系，
  随时按它收工，没点到的人这时才归位到最后那一块。不点名当然也可以，自习照跑。
- **结束**：按「结束自习」先问一句（这一下不可回退：定格之后不能接着走，要续上只能
  另开一场），确认后这一场定格、看板收起回班级列表。已经结束的场次只能在
  「记录」里看 —— 那里每场一行：开始、结束、时长、在座、离开人次、超时几人。

一到自习就在落盘，刷新或关掉浏览器再打开，回来接着看 —— **有一场还没结束就直接盖上
自习看板**，不必自己再进一次。

## 自习里能做的三件事

上课时什么情况都能遇到，所以除了往下走，还给了两手：

| 动作 | 做什么 | 什么时候能用 |
| --- | --- | --- |
| **暂停自习** | 自习时间停住；**外面的人也一起停表**（不然暂停二十分钟再回来，谁都变成超时了）。按「继续自习」接着走 | 自习中 |
| **重新开始** | 结束这一场，另开一场（会先问一句）。旧的那一场留在记录里，不删 | 自习中 |
| **结束自习** | 先问一句，确认后这一场定格、收起看板回班级列表 | 自习中 |

暂停期间：时钟压暗（不另挂一颗「已暂停」的牌子 —— 底栏那颗已经变成「继续自习」了）；
不响超时铃；不切待机屏（那时什么都没在计时，屏幕上留着那一屏比换成大钟有用）。正暂停着
按「结束自习」会把那一段合上，不会多算。

## 看板上有什么

**自习时间**是这一屏最大的字：从**开始自习**那一刻算起（点不点名都一样，一按下去
就在走），一律写成 `时:分:秒`，小时位一直留着 —— 大屏上的数字宽度得稳，走到一小时
不能忽然跳一下。还没开自习时它是 00:00:00 且颜色沉下去；暂停时停住并压暗。

右边四个计数：在座、没来、离开、超时。每个数前面带自己的色点 —— 这四个数同时就是
四色的字典，不必再另起一行图例。「在座」把临时离开的人算在内（他们到了，只是这会儿不在
座位上），所以「离开」与「超时」是「在座」的子集；「没来」加「在座」等于应到（因此「应到」
不单列）。

「离开」与「超时」大于 0 时数字点亮：0 是常态，不该一直在屏幕上发亮。「离开人次」这一场
的账去「记录」里看。

格子的高度按**最坏情况（三行：名字 + 原因 + 计时）**算出来，三套主题各按自己的字号定：
童趣 101px、标准 87px、简洁 74px。定死一个值不行 —— 原来写死的 74px 只够两行，有人离开时
多出来的那行会溢出格子，上下都被相邻两行的格子盖住，名字和计时看着就像被裁了。按三行都放
得下还有个好处：谁离开、谁回来都不会让格子变高变矮，一整屏的排布不跟着跳。

人一离开，格子第二行就换成离开的原因（没填备注的写「离开中」）。

## 几个人一起出去

课间一起出去的那几位，一个一个点、一次次挑备注太啰嗦：按看板上的**多选**，格子右上角
长出勾选框（**只在座的人有** —— 没来的谈不上离开，已经在外面的人也不必再记一次，点上去
只顶一句提示），点一下勾一个，选中的靠那颗勾认。勾完按**记离开**，浮层照样只问
一次备注，同一条备注、同一个起算时刻落在他们每个人身上 —— 一起出去的人本来就该从同一
秒算，各记一个时刻反而是假数据。

蒙版上那一排动作钮在多选时全让位，只剩「已选 N 人 · 记离开 · 取消多选」—— 同一份
道理与班级列表的多选一样：这时候按格子是「选他」，不是别的意思。一个都没勾时「记离开」
按住不让按（按下去只会开一层空的备注窗）。**Esc** 退多选，**收起**看板也一样退 ——
回来时那几颗勾还在，反而像没退出去。多选中不切待机屏：那会儿老师正一个个勾人。

## 临时离开的备注

点一个在座的人会先问一句备注，挑一条就开始计时，还能再补一句话。**一条都不挑也行** ——
那就是默认的黄、不限时，纯粹计个数。

常用备注在「班级设置」里维护，**一条一行、三个字段**：

| 字段 | 说明 |
| --- | --- |
| 文本 | 写在格子上、导出文件里的说法（「上厕所」） |
| 颜色 | 他离开期间格子刷的颜色，六选一，默认黄 |
| 分钟数 | 超过这么久转红并出声；**留空就是不限时**（只计个数、不响） |

挑备注的那个浮层里，每个选项前面画着它自己的颜色，后面写着分钟数 —— 挑的时候就能
看见「这条几分钟算超时」，不必回设置里翻。

补的那句话支持语音输入：走浏览器原生的语音识别（`zh-CN`）。**这是可选增强** ——
多数实现要把音频送到厂商服务器，国内网络下常常起不来；不可用时按钮会置灰并说明
原因，备注照样能手打或挑模板。

## 导入花名册

**看内容，不看扩展名。** 老师手上的名单来自各处，名字常常不作数，所以按开头几个字节与
文本长相认：

| 拿到的文件 | 实际是什么 | 认不认 |
| --- | --- | --- |
| `.xlsx` | ZIP（OOXML） | 认 |
| `.xls` | OLE2 复合文档 + BIFF8（Excel 97-2003、WPS） | 认 |
| `.xls` 但其实是 HTML 表 | 教务系统「导出 Excel」最常见的产物 | 认 |
| `.xls` 但其实是 XML 表格 | Excel 的 XML Spreadsheet 2003 | 认 |
| 别的 | —— | 报错说明，不猜 |

编码按文件自己声明的解（教务系统的导出常是 GBK 系）；声明与内容不符时（少数导出会
把 UTF-8 存成 gb2312 的名字）以能被严格 UTF-8 解通为准。

认列靠首行文字：有一列写着「姓名」或「名字」，学号与座位列可选。没有表头时退回
「第一列学号、第二列姓名」。多张表时先找叫「名册」的，没有就逐张试到读出学生为止 ——
教务系统的导出常把标题、说明各占一张表。

导出的一直是 `.xlsx`：Excel、WPS、Numbers 都打得开，不必再写一套二进制写出。
「导入班级文件」也只认本工具导出的 `.xlsx`（那是整班的数据，不是花名册）。

## 一个班一个文件

导出的是**这个班的全部**：班级设置（含出声开关、补响间隔、待机时间、教室响度的阈值 ——
它们都按班为单位）、常用备注（含各自的颜色与时长）、名册、每一场记录、每一场的点名明细、
离开明细与暂停明细，共七张表：

| 表 | 内容 |
| --- | --- |
| 班级 | 名称、格子大小、出声开关、补响间隔、待机时间、响度阈值、导出时间 |
| 备注模板 | 序号、文本、颜色、时长（分钟；空着是不限时） |
| 名册 | 学号、姓名、座位 |
| 会话 | 每场一行：开始 / 结束时刻、应到 / 在座 / 没来 / 离开人次 / 累计离开 / 暂停次数与时长 |
| 点名明细 | 每场 × 每人一行：是否点到（「否」就是记下的没来） |
| 离开明细 | 每人每次一行：离开时刻、归来时刻、时长、是否超时、备注模板、补充说明 |
| 暂停明细 | 每次暂停一行：暂停时刻、继续时刻、时长 |

离开明细里的两块备注分开写：**模板**那一列是老师认得出的说法，回来时靠它把颜色与时长
接回去；**补充说明**是当场补的那句话。

时间在表里写成 Excel 日期而不是文本，老师拿到文件能直接排序与筛。导入时按同样的表
重建；**检测到同名班级会问一句「覆盖还是另建副本」**，不会闷声盖掉。

## 文案

### 什么时候才弹一条提示

只在**结果看不见**的时候弹。动作的结果如果已经在屏幕上（钮换了字、格子换了色、遮罩收了），
就不再报一遍 —— 报一遍反而是噪音，而且它挂在顶上，会盖住老师刚看的东西。

留下来的只有三类：

| 情形 | 例子 |
| --- | --- |
| 点了没反应，得说清为什么 | 点一个没来的人的格子 · 往多选里勾一个没来的人 · 点一场已结束的自习 |
| 按了没成，得说清怎么办 | 读表失败 · 表里没有「姓名」列 · 教室响度开不起来 · 语音识别不可用 |
| 屏幕上没有别的地方能看出这件事 | 点名落盘（「记下 2 人没来」）· 名册念完了 |

**删掉的那一类**：暂停 / 继续 / 静音 / 自动待机 / 记离开 / 记归来 / 保存设置 / 删除班级 ——
这些的结果都在屏幕上（时钟压暗、钮换字与颜色、格子换色、卡片从列表里消失），一条提示条
只是把老师刚看的东西盖住。

去掉提示条之后，「暂停自习」那颗钮要换的字得靠一次整块重画（见 `doPause` 的 `forceRender`）——
原来那一下是由提示条兜着的。

### 措辞

按钮与提示一律写**结果**，不写机制，也不用口语：

- 「记下离开」（不是「开始计时」）· 「记下 N 人没来」（不是「完成」）· 「待机屏」（不是
  「大时钟」）· 「自动待机」（不是「本场不切」）· 「教室响度」（不是「听教室」）·
  「重新开始」（不是「重开一场」）· 「重新导入」（不是「导回名册（换成表里的）」）。
- 图标不单独表意：一颗钮上写着的字说完这件事，图标只是帮眼睛先认出形状。所以「自动待机」
  一直用同一个图标（一块屏 + 盘面），开与关看那颗钮的按下态 —— 换成太阳 / 月亮反而要人
  去猜「太阳是开着还是关着」。
- 提示条与确认框用书面语：「他是没来的。到没到在「点名」里改」「无法读取该文件」
  「记下 2 人没来」—— 不带「就行」「试试」「再点停」这类口语。
- 报错给**下一步**，不给技术细节：读表失败一律是「无法读取该文件，请换一份 .xlsx 或 .xls」，
  原始错误进 `console`。

## 主题

三套：童趣（小学）、简洁（高中）、标准。按班设置（设置里那一项叫「格子大小」——
老师挑的是这个班的名字写多大、一屏摆几个，不是一套设计语言的代号），同一个工具给不同的
班用，格子的大小与密度跟着换，颜色的语义与亮暗都不动。

它是**另一个轴**：与亮暗无关，两者叠加。所以「童趣 + 暗」「童趣 + 亮」都对，格子一样大。
字号挂在一层，看板与浮层共用 —— 点名层是看板那一层的兄弟节点，字号只挂在蒙版上的话，
同一个班会出现看板 24px、点名层 20px。

## 数据在哪

只在这台机器的这个浏览器里，**换浏览器或清站点数据就没了** —— 这是本工具的既定
形态。数据放在 IndexedDB；启动时向 `navigator.storage.persist()` 申请持久化配额，
避免 Safari 的七天不活跃驱逐。申请被拒不影响使用，只是那份数据可能被系统回收。

要换机器或留档，用「导出 xlsx」。

## 怎么跑

工具页是**静态页**：不经过打包器，也不依赖工具箱外壳的样式。可以直接把它当普通
静态站点打开：

```bash
# 仓库根
python3 -m http.server 5210 --directory src/tcb/toolbox_service/tool_sources/tools_public/edu/study-hall/site
```

浏览器打开 <http://127.0.0.1:5210/>。要语音输入得走 HTTPS（`localhost` 例外）。

发布走工具箱那一套：本目录的 `tool.json` 声明为一个 `kind: "h5"` 的工具，
`site/` 下的文件由 `toolbox_service` 发布，工具箱壳从发布地址装载。清单契约见主仓的
`docs/containers/toolbox_app/附录/01-工具清单.md`。

## 目录

```text
site/
├── index.html          页面骨架、首屏那一遍亮暗、挂样式与入口
├── styles.css          亮暗两档 × 两块面 × 三套格子大小，看板与浮层的样式
└── js/
    ├── app.js          启动与主循环：走秒、待机判定、超时提醒、键盘的退路
    ├── state.js        一份状态、往库里写的动作、整块重画的分发
    ├── classes.js      班级列表：班级卡、多选、导出与删除、共用顶栏（含亮暗那颗钮）
    ├── mode.js         亮暗：现在哪一档、换一档、记在本机
    ├── board.js        自习看板与待机屏，以及走秒那条定点更新的路
    ├── overlays/       七块浮层：新建班级 / 记离开 / 设置 / 记录 / 同名 / 点名 / 教室响度
    ├── dom.js          `h`、内联图标、浮层壳、全屏、浮层焦点
    ├── format.js       时长与日期的写法
    ├── roster.js       读花名册（认列、取名学生）、把文件下下来
    ├── domain.js       状态机、颜色与超时推导、统计、该响哪几条、老数据补齐。纯函数，不认识浏览器
    ├── store.js        IndexedDB 两个 store（classes / sessions）
    ├── readSheets.js   按内容读表格（不看扩展名），花名册走这里
    ├── klassFile.js    一个班 ↔ 一份 xlsx
    ├── xlsx.js         最小 xlsx 读写（自己写的 ZIP + 够用的 OOXML）
    ├── cfb.js          OLE2 复合文档的读取（.xls 是个小文件系统）
    ├── biff.js         BIFF8 的读取（Excel 97-2003 的单元格）
    ├── textTable.js    HTML 表与 XML Spreadsheet 2003
    ├── sound.js        超时提示音，WebAudio 现场合成
    └── speech.js       语音：备注的语音输入、点名层把名字念出来
```

`state.js` 与视图之间成环：视图要调 `state.js` 的动作（`onClick` 得接得上），`state.js`
又要画视图。环上只走函数声明与已经建好的对象，模块求值期谁也不调谁。

`xlsx.js` 是自己写的：工具页不经打包器，拿不到 npm 上的表格库。压缩走浏览器的
`CompressionStream('deflate-raw')`，不支持时退回不压缩的 stored。批量导出复用的也是
它 —— 一个工作簿本来就是 ZIP，拿同一套打包代码把几份 xlsx 装成一个归档即可。

`cfb.js` / `biff.js` / `textTable.js` 同理是为读 `.xls` 写的：前者把复合文档当成
一个很小的文件系统把 `Workbook` 流取出来，中间那层按 BIFF8 的记录切单元格，后者对付
被存成 `.xls` 的网页表格 —— 三者都不依赖浏览器 API，验的时候能在 Node 里跑，
拿 `xlrd` 这类只认 `.xls` 的外部库当裁判逐格对。
