# 演练场 playground

按语言切换目录，左侧选条目，右侧按条目类型装配出工作区。本文件不发布，只有 `site/` 进产物。

## 信息架构

```text
Language  语言（左列顶段的下拉）→ 换整棵目录
Search    搜索（左列中段）→ 只过滤目录，不动右侧
Catalog   分组 → 条目，两层
Entry     类型决定右侧形态
Variant   一棵布局树 + 一张「槽位 → 面板」映射
Pane      只管画自己，不知道自己在哪
```

条目类型只有三种，各自对应一个默认变体：

| kind | 变体 | 形态 |
| --- | --- | --- |
| `doc` | `L-doc` | 单栏文档，无面板头 |
| `code` | `L-code` / `L-code-preview` | 按有没有运行器取一个 |
| `exercise` | `L-exercise` | 题目 \| （编辑 / 日志）\| 预览 |

`code` 再看运行器：`runner` 为 `none` 就降级成单栏。条目上的 `runner` 覆盖语言默认，
所以同一门语言里也能演示降级。

## 布局树

```text
LayoutNode = split(dir, ratio, a, b) | slot(id[, fixed])
Variant    = { tree, panels }
```

- 不带 `fixed` 的子节点按 `ratio` 分空间；带 `fixed` 的按像素占位，但允许随视口退让
  （`min(Npx, 40vw / 26vh)`），横向是宽度、纵向是高度。预览列宽度、日志高度都用它。
- 比例在写入前先归一：一侧固定成像素后，另一侧补满剩下的份额，不留给空白。
- 面板在整个会话里只有一份实例，切条目、切变体都只搬根元素，不重建；
  编辑器的光标与未保存内容、iframe 的运行状态都活着。
- 间隔只由 `.split` 的 `gap`（12px）给，面板不画分割线。

## 容器规则

> 左列下沉一层，工作区是底座，工作区里的面板一律成卡。

卡片不额外留白（留白会让面板头与相邻面板错开），靠圆角与描边表达层级；
左右的 16px 底座边距 + 面板间 12px 间隙，就是全部间距来源。

## 工具条归属

没有通栏顶栏，操作跟着作用对象走：

- 语言作用于整棵目录 → 左列顶段
- 运行 / 重置作用于编辑内容 → 编辑区面板头
- 预览、日志的自身操作 → 各自面板头

`L-doc` 没有编辑区，于是自然没有运行按钮。

## 编辑器

`site/vendor/monaco/` 是 Monaco（VS Code 的编辑器内核）的裁剪版，运行时从本地加载，不连 CDN。
只装三样东西：编辑器内核、主题、六种语言的 Monarch 词法（JavaScript / TypeScript / CSS /
HTML / Markdown / Python）。

- 没有语言服务，因此也没有 web worker：没有补全、跳转、类型检查与校验。
- 主题 `playground-dark` 里的颜色按设计稿取，注释、关键字、正文三档是设计稿给的，
  字符串、数字、标点在同一色系里补齐。
- 状态条的光标位置、语言、编码换行都是真的；草稿按「语言/条目/文件」落到
  `localStorage`，不跨设备。

## 占位范围

| 部件 | 状态 |
| --- | --- |
| 目录内容 | 占位示意，编排成能演示四种变体与 tabs 有无 |
| 目录搜索 | 按条目名与类型过滤，不搜正文 |
| 编辑器 | Monaco，有行号、语法高亮、当前行与状态条；无补全 |
| 运行器 | 只跑能直接在浏览器执行的文件；TypeScript 编译与 Python 运行器**未接入**，面板明示 `not_implemented` |
| 练习判题 | 未实现，题面写明「不判题」 |
| 草稿 | 存本机 `localStorage`，不跨设备（云同步未接入） |

## 未定项

- 目录内容最终是内置静态数据还是走接口动态拉
- 除浏览器可执行的语言外，要不要接远端执行
- 草稿要不要接 `store.kv` 云同步
- 预览面板隐藏时 iframe 继续运行还是暂停
- 分隔条拖动与面板折叠 / 最大化要不要做
