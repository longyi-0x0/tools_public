# 抽奖台（lottery）

导入一份 xlsx 就能开抽。同一份奖项与名单支撑两种方向：

- **奖品抽人**：选一个奖项，从没中过的人里抽 N 个。适合年会、晚会，画面是大屏。
- **人抽奖品**：指定一个人或按名单顺序，按各奖项剩余名额加权抽一个奖。适合摊位、抽奖箱。

两种方向在新建抽奖时选，之后在详情底部可以改（还没开过奖时）。名单与奖品各自维护，可以给多场抽奖复用。

## 用法

左边是列表，右边是选中项的详情。

1. **名单**（左下角切换）：左上角的 `+` 上传一份含「姓名」列的 xlsx；点列表里的名字在右边改、加、删。
2. **奖品**：同理，上传含「奖品名称」「数量」两列的 xlsx。
3. **抽奖**：左上角的 `+` 打开新建弹窗，选抽法（奖品抽人 / 人抽奖品）、名单、奖品、每次抽几人、形态。也可以直接在弹窗里上传 xlsx。
4. 详情右侧是这场抽奖自己的奖品与名单副本：可以改名字、调名额、补人、删人（名额改不到已经抽出去的数量以下）。
5. 详情底部有「开始抽奖」；「彩排」走一遍流程，结束后可以清空。
6. 抽奖页占满整屏：左边是待抽的签（或票），右边是舞台。全屏是页内的开关，全屏时队列让位，只剩舞台。
7. 详情底部的「结果」开结果弹窗：按奖项分组看、撤销、导出 xlsx、清空记录。

名额与中奖标记都从开奖记录推出来，撤销就是把最后一条记录丢掉，两边不会对不上。抽奖页支持键盘：空格开 / 停，↑↓ 换一行，退格撤销，Delete 作废，Esc 退出。状态存在浏览器 localStorage，刷新不丢。

## 表的结构

| 表 | 列 | 说明 |
| --- | --- | --- |
| 奖品 | 奖品名称 | 必填 |
| | 数量 | 名额，缺省 1 |
| | 权重 | 人抽奖品时用，按「剩余名额 × 权重」参与抽签，缺省 1 |
| | 等级 | 选填，暂时只读入不展示 |
| 名单 | 姓名 | 必填 |
| | 部门 | 选填 |
| | 工号 | 选填，导出结果时带上 |

- 表名带「奖」按奖品表读，带「名单 / 人员 / 参与人」按名单表读；认不出来时看表头。列的顺序随意。
- 表头里认这些字：`奖品名称 / 奖项名称 / 奖品 / 奖项 / 名称`、`数量 / 名额 / 个数 / 份数`、`权重 / 概率`、`姓名 / 名字 / 参与人`、`部门 / 科室 / 单位 / 班级`、`工号 / 员工号 / 编号 / 学号`。
- 只读 `.xlsx`。`.xls`、`.csv` 请先另存。空行、没名字的行会跳过并在导入页列出来。
- 站里的「模板」按钮会生成一份带示例的 xlsx。

## 规则与边界

- 默认「已中奖的人不再进池」。关掉后同一个人可以重复中奖。
- 一次抽几人在新建时定好，之后在详情底部改；名额或人不够就按能抽的抽。
- 人抽奖品时，配额抽完的奖项权重为 0，自然退出抽签；全部抽完就停下。抽奖页默认按名单顺序取下一位，也可以点任意一行。
- 嵌在工具箱里时浏览器不给 iframe 全屏权限，「全屏」会提示一句；舞台本身就是铺满视口的一层。
- 解析、存储、导出都在本机浏览器里完成，没有服务端，也不上传文件。
- 没有账号、多人同步与扫码加入。换设备要重新导入，旧设备的结果可以导出带走。

## 目录

| 路径 | 内容 |
| --- | --- |
| `tool.json` | 工具箱清单（`kind: h5`，`tags: ["scene"]`） |
| `site/index.html` | 单页外壳 |
| `site/styles.css` | 暗场剧场风的设计令牌与四面布局 |
| `site/src/data.js` | 名单库、奖品库与抽奖活动三份数据；新建时复制副本 |
| `site/src/engine.js` | 抽奖引擎：池、抽样、名额、撤销（纯函数） |
| `site/src/workbook.js` | xlsx 读入、列映射、模板与结果导出 |
| `site/src/xlsx.js` | 最小 xlsx 读写（ZIP + OOXML），与 `study-hall` 同源 |
| `site/src/store.js` | localStorage 存取 |
| `site/src/stages/` | 四种舞台形态 |
| `site/src/main.js` | 左右两栏界面、弹窗与抽奖页 |
| `tests/engine.test.mjs` | 引擎单测，`node --test` |

## 验证

```bash
npm test          # 引擎：抽样、名额、撤销、不重复、降级
```

页面不依赖构建。要本地看，在 `site/` 下起一个静态服务即可：

```bash
python3 -m http.server 8787
```

## 发布

随工具箱发布：目录放在工具仓库的 `tools/lottery/`，发布器只收 `tool.json` 与 `site/`。`package.json` 与 `tests/` 仅用于本机跑测试，不进发布包。
