# 花语（petal-drift）

一个网页端 3D 场景：你操控**一群飘浮的花瓣**掠过风格化的草原，所过之处草色由枯转翠、
鲜花次第绽开；天空是体积云，云影一片片扫过山丘；停下时镜头缓缓推近，背景融成柔焦。

纯前端、零构建：`index.html` + ES 模块 + 本地 three.js（`site/vendor/three.module.js`，
r160）。页面自己不带任何网络请求 —— 没有 CDN、没有字体外链、没有音频素材，声音是
Web Audio 现场合成的。

**需要 WebGL2**（浮点渲染目标 + 顶点纹理采样）。浏览器不支持时页面底部会显示错误浮层。

## 操作

| 键 | 作用 |
| --- | --- |
| `W A S D` / 方向键 | 引导花瓣群 |
| 鼠标拖动 | 环视；松手 1.6s 后镜头自动回到航向后方 |
| 滚轮 | 推拉镜头 |
| `Shift` | 疾风加速 |
| `空格` | 升起（`Ctrl` / `Z` 下沉） |
| `1`…`7` | 切换天气：晓雾 / 晴光 / 风起 / 阴云 / 细雨 / 夕照 / 月夜 |
| `N` | 下一种天气；自动流转默认开启 |
| `C` | 电影黑边 |
| `F` | 自由视角（关闭自动跟拍） |
| `R` | 清空花田与草色记忆 |
| `M` | 静音 |
| `H` / 右上角 ☰ | 设置面板（画质、景深、泛光、雾气、曝光、浓郁度、颗粒、声音、风力、花瓣数、开花半径…） |
| `P` | 暂停 |

移动端：屏幕**下三分之一**拖动是摇杆前进，其余区域拖动是环视。

首次点击画面之后才有声音 —— 浏览器的自动播放策略要求一次用户手势。

## 显示方式

**VR（第一人称沉浸飞行）**：页面右上角常驻一颗「进入 VR」按钮，点它直接在头显里进入第一人称
飞行。按钮**不做条件显示** —— 有些运行时在真的请求会话之前不报告设备，而头显上没地方看控制台；
进不去时页面底部会写明是哪一步被拒（没有 `navigator.xr`、不是 https、`requestSession` 的原因），
设置面板的「状态」里也留一份。VR 下走一条不依赖后处理的直出管线：雾与调色前移到场景材质内部（`#ifdef VR_FOG`
隔离，2D 路径不编译该分支），景深、暗角、边缘色散、胶片颗粒、电影黑边全部关闭 —— 这几项在
双目下会致晕或产生双目竞争，不是性能取舍。体积云在 VR 下烘焙进 cubemap 穹顶。

**从这里装载的限制**：工具箱把页面放在 iframe 里，满铺整个工作区；页面内的指针锁定、全屏
这类能力要浏览器直接给的权限，在 iframe 里可能拿不到。想要完整手感就在工具详情里按
「在浏览器打开」。
