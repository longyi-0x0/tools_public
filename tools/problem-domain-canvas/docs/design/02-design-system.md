# 问题域画板 · 设计系统 v6

> 本版与实现同步于 2026-11-17：缩放 30%–250%；画布工具条 5 枚（`适配 · − · 100% · + · 图`，第 5 枚开合小地图）；手势与快捷键见 03 §2.5；实体行 `＋` = 新建同级实体。

底座：浅 / 深双主题共用同一套结构，**默认 `body[data-theme="light"]`**（静态稿写死在 `body` 上），`[data-theme="dark"]` 可切；两域共用一套语言，靠「域切换」换渲染面，**不换配色**（删掉「问题=蓝 / 解=青」的双色）。

## §1 设计原则（4 条）

1. **一屏只答一个问题**：问题域只出「要解决什么」，解域只出「怎么解」，两域不共用画布、不共用节点形状。
2. **只有一个主色**：淡紫 `--pd-accent` 用于选中 / 域切换 / 焦点；绿只标「已保存 / 已回答 / 已通过」，琥珀 / 红只标检查严重度；域归属靠位置 + 文字区分，不靠色相；其余一律中性灰（§2.3）。
3. **线是最后手段**：先问「能不能用间隙 → 能不能用底色差 → 能不能用阴影」，三样都答不上来才画线；每屏 1px 直线 ≤ 6 条（§6）。
4. **留白是功能**：每屏 5–8 个元素，宁可横向滚动也不缩节点，任何视觉元素必须对应一条节点/关系语义。

### §2.3 配色纪律（硬规则）

1. **单主色**：全屏只有一个强调色（淡紫 `--pd-accent`）。不设「问题域 = 蓝 / 解域 = 青」的域色，域切换靠位置 + 文字，不靠色相。
2. **彩色只占小面积**：底板、面板、画布一律中性（`--pd-n-*` / `--pd-bg-*`）；彩色只出现在 6px 圆点、胶囊、选中底、1.5px 环、检查标记这类小元素上。
3. **绿只做正向**：`--pd-teal-3` 仅用于「已保存 / 已回答 / 已通过」；实体圆点、画布边、约束块不得用绿。
4. **琥珀 / 红只做严重度**：`--pd-amber-*` = 警告、`--pd-red-*` = 错误；不得用于普通状态、类型区分或装饰。
5. **右列顶部不设背景，且是信息位**：`.statusbar` 直接落在玻璃底板 `--pd-bg-1` 上——无背景、无圆角、无阴影、无下边框，高 44；左是「当前在看什么」的标题（8px 类型点 + 16/600 标题 +（可选）12px 父级路径），右是导出菜单图标、撤销 / 重做两枚图标按钮、「已保存」与主题演示；**缩放、检查摘要、收起图标都不在这里**。
6. **收起面板只有一套入口**：收起 / 展开只由两条边界上的 24px 把手 + `[` `]` 承担，右列顶部不出现收起图标；把手静止态 `opacity:.4`、悬停 / 聚焦 1，所在块收起后常驻可见。

## §6 层级与线条预算

这一节是本系统最硬的约束：**分层先试三件套，画线是最后手段**。

1. **分层三件套（按序尝试）**：12px 间隙（底板色透出来）→ 底色三级（`bg-1` 底板 < `bg-2` 面板 < `bg-3` 卡片）→ 两档阴影（`--pd-sh-1` 静态卡片 / `--pd-sh-2` 浮层）。三样都答不上来，才允许画一条线。
2. **分区靠间隙与底色差**：三区之间、顶栏与主体之间、底栏与主体之间一律 12px 间隙，底板从缝里露出；**禁止**用 1px 竖线切栏、禁止顶栏下边框。
3. **线条预算**：每屏可见的 1px 直线 **≤ 6 条**（画布连线、节点轮廓、点阵网格不计入；底栏上边框最多 1 条）。计数口径见 §9 第 3 条。
4. **卡片不描边**：底 = 比所在面板亮一级（`--pd-bg-3`）+ `--pd-sh-1`；悬停只加深阴影或提亮底色，不加边框、不加左侧竖条。
5. **卡内分组用嵌套淡色块**：同色系、圆角 12、无边框、无横线；右栏「检查」「关联」「解域支撑」三组必须这么处理，组间只用 8px 间隙。
6. **列表项 hover / 选中用胶囊底色**：圆角 999、无边框、无下划线、无左侧竖条；选中态额外 `--pd-sh-1`。
7. **画布**：网格为 24px 间距点阵（`--pd-line-1`，不透明度 ≤ 0.6，不画实线 / 虚线）；节点为无描边卡片，选中才给 1.5px `--pd-accent` 环。

## §7 布局

- 区宽与断点以 `03-ui.md` §2 为准（左 264 / 中 auto / 右 340，`<1200` 左 240 + 右栏覆盖式抽屉 + 隐去「已保存」）；本文只定视觉分层：**三区之间 12px 间隙 + 面板圆角 12 + 零分隔线**。
- 右列顶部状态行高 `44px`，**无背景 / 无圆角 / 无阴影 / 无下边框**，直接落在 `--pd-bg-1` 玻璃底板上，与画板之间只留 12px 间隙；左 当前选中标题（信息位，未选中时为「未选中」）、右 导出菜单 + 撤销 / 重做（disabled 态可见）+ 已保存 + 主题演示，不放视图 tab、不放缩放、也不放收起图标。缩放四件在画板右上角的悬浮工具条（高 30），检查摘要在左列底部检查行（高 36）。
- 画板与详情**都能收到 0**（不缩成窄条），各有一个 24px 把手，但落点不同：画板把手贴画板左缘（左列与画板之间的 12px 间隙），详情把手长在详情头部、贴**内容区右缘**（详情收起时随详情贴到内容区左沿，窄屏抽屉下贴抽屉左沿）；**不允许两块同时收起**——要收其中一块而另一块已收时，先把另一块放回来，否则右列只剩一条工具条。
- 画布节点最小间距 32px（横向）/ 40px（纵向），不自动压缩；画布网格随主题换 `--pd-line-1`。
