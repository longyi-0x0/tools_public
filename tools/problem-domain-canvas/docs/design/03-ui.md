## §1 两屏各说了什么

### 屏 1 · 问题域（默认）

左树 = **问题树**：P0 如何正确处理选课？→ P1 选课资格 →（P1.1 容量检查 / P1.2 冲突检查），另 P2 状态更新，共 5 行；行内 = 缩进 · 标题 · 状态文字（已回答 / 分析中 / 未澄清 / 暂缓）。画板 = 问题树画布（7 节点 / 6 条边，3 处检查标记 C4 / C2 / C5）。详情 = 选中 P1.1 的属性（类型 / 状态 / 上级 / 已知与假设 / 正反例）、关联、检查（3 条）。

### 屏 2 · 解域

左树 = **两段扁平列表**，不展开字段/行为/约束：

- 「实体」4 行（学生 / 课程班次 / 选课记录 / 教师）；行内 = 类型点 · 名称 · 支撑徽标（`P1.1`），未支撑的实体只在行尾给**一个红点**（不分组、不加第三段）。
- 「关系」2 行；行内 = `A —持有→ B` + 行尾基数（`1:N`）。

画板 = 领域模型（4 实体 + 1 行为 + 2 约束 = 7 节点 / 6 条边，1 处 C6 标记）；点左树实体或关系，画板对应卡片/连线高亮；选中 P1.1 时只留支撑它的元素（其余 `opacity:.3`）。详情 = 实体的属性（主键 / 字段 / 支撑的问题）、关联、检查（1 条 C6 提示）、支撑的问题。**字段、行为、约束、支撑关系一律只在详情栏出现，左树不放。**

## §2 版式：两列（没有全局顶栏）

### 2.1 骨架

- `body > .app`：`display:grid; grid-template-columns:264px minmax(0,1fr); gap:12px; padding:12px; height:100%`。**没有页面级顶栏**，`.app` 直接是两列（左 `.col.left`、右 `.col.right`）。
- 左列是 `--pd-bg-2` 面板 + 圆角 12；右列**不整体成卡**——顶部状态行直接落在底板 `--pd-bg-1` 上（§2.3），画板与详情各自是一张面板卡（§2.4）。
- 收起任一块：`body[data-right="off"] .content{grid-template-columns:minmax(0,1fr) 0}` / `body[data-canvas="off"] .content{grid-template-columns:0 minmax(0,1fr)}`；左列 264 不变（它不可收起）。

### 2.2 左列：一行头 + 树 + 底部检查行（整页高）

- 顶行 `.left-hd`（`display:flex; align-items:center; gap:8px; height:40px; padding:0 8px 0 16px`）**只有两样**：工作区名 `.ws-name`（14px / 600 / `--pd-fg-1`，**只出现在这里**）与右侧域切换 `.dom-switch`（胶囊 + 2px 内边距，两枚按钮各 52×22；选中 `--pd-bg-3` + `--pd-accent` 文字 + `--pd-sh-1`）。**没有第二行**：「目标：如何正确处理学生选课？」整行删除，「领域」标签也删除——切换控件自己已说明域，名字与切换同一行垂直居中。
- 树（`.tree`）：`flex:1; overflow:auto`，占满左列剩余高度、可滚；左右内距 8、底部不留白（留给检查行）；**不可收起**（无 chevron、无快捷键、无开关）。
- 树的内容随域变化：`body[data-domain="problem"] .tree.solve` 与 `body[data-domain="solve"] .tree.problem` 双双 `display:none`。问题域 5 行；解域 2 段共 6 行（实体 4 + 关系 2）。
- 行样式：30px 高胶囊，无描边；悬停 `background:color-mix(--pd-bg-1, transparent)`；选中 `--pd-bg-3` + `--pd-sh-1`。圆点只用主色 / 正向 / 中性三档，不用域色。
- 底部检查行 `.left-ft`：高 36、`margin:8px`（与树之间只隔 8px）、无底色 / 无阴影 / 无边框——**不是卡片，直接贴左列底部**；左侧 8px 严重度圆点（警告 `--pd-amber-3` / 提示 `--pd-amber-4`）+「检查 3 条 · 2 警告 1 提示」（解域为「检查 1 条 · 1 提示」）+ 右侧 `›`；点击 → `body[data-pane="checks"]`，详情「检查」分组浮起 1.5px `--pd-accent` 环。

### 2.3 右列顶部：状态行（44，无背景）

`.statusbar`：`height:44px`、`background:none`、`border-radius:0`、`box-shadow:none`、无下边框，`justify-content:space-between`，**直接落在玻璃底板 `--pd-bg-1` 上**，与下面画板之间只靠 12px 间隙分开。它是**「当前在看什么」的唯一指示**，按信息位用，不当装饰：

| 组 | 内容 |
| --- | --- |
| 1 左 标题位 | 8px 类型圆点（色随节点类型，问题 = `--pd-accent`）+ 标题 16px / 600 / `--pd-fg-1`，问题带编号（`P1.1 容量检查`）；其后可跟极小父级路径 `P1 ›`（12px / `--pd-fg-3`）帮助定位，**不做成面包屑导航条**；解域显示选中实体名（`学生`，后跟 `支撑 P1.1`） |
| 2 右 | 「✓ 已保存」11px / `--pd-fg-3`；主题演示「深/浅」（`title="演示用"`，只用于静态稿） |

未选中任何节点（`body[data-sel="none"]`）：左位整块换「未选中」12px / `--pd-fg-2`，不留空白、不放大字。缩放四件在画布悬浮工具条（§2.4 首条），检查摘要在左列底部（§2.2），收起图标已删（只留把手，§2.4.1），这一行都不再出现。

### 2.4 下方内容：画板 + 详情，两块都能收

- `.content`：`grid-template-columns:minmax(0,1fr) 340px; gap:12px`。画板 `.stage` 与详情 `.detail`（340）**各可收到 0**（收到 0，不是缩成窄条）。
- 画布悬浮工具条 `.stage-tools`：贴画板右上角（`position:absolute; top:46px; right:14px`），高 30、内距 4、圆角 999、`--pd-bg-3` + `--pd-sh-2`、**无边框、无 1px 直线**；内容 `适配 · − · 100% · +`（四件都在）。它是画板自己的控件，不占右列顶部状态行，也不随画布滚动。
- 2.4.1 两个把手（**收起 / 展开的唯一入口**）：各 24×24 圆、`--pd-bg-3` + `--pd-sh-2`、无描边，**各贴自己那条左边界**——画板把手 `.hc` 落在左列与画板之间的 12px 间隙（`position:absolute; left:-18px; top:50%`），详情把手 `.hd` 落在画板与详情之间的间隙；**静止态常驻可见 `opacity:.4`**，悬停对应面板 / 聚焦时提到 1；`title` 写动作 + 快捷键：展开时「收起画板（[）」/「收起详情（]）」，收起后变「展开画板（[）」/「展开详情（]）」，chevron 同步翻转 180°。
- 2.4.2 **互斥（硬规则，02 §7 同步）**：不允许两块同时收起，否则右列只剩一条工具条——要收画板而详情已收 → 先把详情放回，反之亦然；静态稿用 `body[data-canvas="off"]` / `body[data-right="off"]` 两个属性表达收起态。触发 = 画板把手 / `[` 键、详情把手 / `]` 键，顶部不再有第二个入口（一个动作只有一处）。
- 2.4.4 详情内部分组（自上而下，嵌套淡色块 `color-mix(--pd-bg-1 32%, --pd-bg-2)` + 圆角 12）：属性 → 关联 → 检查 →（仅解域）支撑的问题。未选中（`data-sel="none"`）时为「工作区概览」。

### 2.5 窄屏 <1200px

左列 220 保持；详情变覆盖式抽屉（`position:fixed` 贴右、宽 340、`--pd-sh-2` 浮起），点左树才滑出；状态行隐去「已保存」，其余保留；左列底部检查行与画布悬浮工具条在窄屏不变。

### 2.6 按工作区记忆

详情开合、画板开合、主题、缩放按工作区存本地偏好（`localStorage` 键带 `workspaceId`），不写进节点数据、不进导出。

- 静态稿把选中固定在 P1.1（`body[data-focus="P1.1" data-sel="P1.1"`），只演示域切换、左树切换、主题切换、画板/详情收放。

## §5 线条预算与两套主题

### 5.1 线条预算（每屏 1px 直线 **0 条**，原底栏那条随底栏一起删除）

| 位置 | 做法 | 1px 直线 |
| --- | --- | --- |
| 两列之间 · 画板与详情之间 | 12px 间隙透底板，无 `border` | 0 |
| 左列头 · 左列底部检查行 · 画布悬浮工具条 · 顶部状态行 · 详情分组 | 无分隔线：状态行不设背景、检查行不是卡片、悬浮条只靠 `--pd-sh-2`、分组用嵌套淡色块 + `--pd-sh-1` | 0（原 1） |
| 画板网格 / 节点 / 胶囊 | 网格 4px 实 5px 空虚线；节点无描边，选中 1.5px 环 | 0 |

### 5.2 两套主题

- 右上角「深/浅」两段；`data-theme="light"` 是**默认**（静态稿写死 `body data-theme="light"`，脚本不再回落到深色），`body[data-theme="dark"]` 可切；不读 `prefers-color-scheme`。
- 令牌名字不新增：原始色阶两套 + 语义层 12 条两组值（02 §2），组件层零改动。浅色：底板/玻璃 `#E9E5EC`、面板 `#FFFFFF`、卡片 `#FBFAFC`、主色 `#6E5CC4`、正向 `#5F8B45`；深色：底板 `#17171B`、面板 `#1F1F25`、卡片 `#26262E`、主色 `#A99BF0`、正向 `#9DC46F`。
- 单主色：淡紫 `--pd-accent` 两域共用（不再有 `body[data-domain="solve"]` 换色）；绿只给「已保存 / 已回答 / 已通过」，琥珀 / 红只给检查严重度（02 §2.3）。

## §6 作废声明

「顶栏 + 三栏（左树 / 中画布 / 右详情）+ 底栏」版式整体作废，改由上两列承担；解域左栏「同一棵问题树」的说法作废，改为实体 + 关系两段；解域把字段/行为/约束挂到左树子项的做法作废，这些内容只在详情栏。v4 的「顶部状态栏是一条带背景的卡片」与「画板永不收起」作废：工具条不设背景，画板可收起。v1 的 14 条参考图差异随 v1 归档一并作废。**v6 作废**：「目标：…」小字整行、「领域」标签、右列顶部的缩放四件与检查摘要胶囊（分别改到画布悬浮工具条与左列底部检查行）、右列顶部的两个收起图标（收起只剩边界把手 + `[` `]` 一套）。
