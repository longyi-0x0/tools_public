## 0 怎么打开静态稿

静态稿在 `docs/design/mockup/`，三个文件：`index.html`、`mockup.css`、（无 JS 文件，切 tab 的脚本内联在 `index.html` 末尾，约 12 行，只改 `data-view`）。

**推荐（本地静态服务器）**

```powershell
cd src\tcb\toolbox_service\tools_public\tools\problem-domain-canvas\docs\design\mockup
python -m http.server 8080
# 浏览器打开 http://localhost:8080/
```

```bash
# macOS / Linux 同上，或用
npx serve . # 若环境已有，不必新装
```

**直接双击 `index.html`** 也能看：本稿**零构建、零外部请求**，没有 ES module、没有 `fetch`、没有远程字体，`file://` 下样式与切 tab 都正常。两点差异要知道：

1. `file://` 下部分浏览器会禁用 `navigator.clipboard`（本稿没用到，不影响）；
2. 中文字体在 `file://` 与 `http://` 下走的是同一套系统字体栈（`--pd-font-sans`），理论上无差；若看到字形异常，先怀疑系统缺「PingFang SC / Microsoft YaHei」，不是稿子引了远程字体。

**怎么读这份稿子**：顶栏 5 个 tab 可点，切换 5 屏；每个 tab 都对应本文 §2 的一节。看到哪块想改，用本文 §3 的组件名 + §5 的 px 值说话（例如「右栏检查项高度改成 44」→ 对不上 02 §3.1 第 17 行，得回到 02 改，不能在 mockup 里改）。

**mockup 的边界（明确不做什么）**：不接数据、不写业务逻辑、不做空态交互、不做拖拽/缩放的真实行为；缩放控件只显示 `80%` 这个状态值。它是**视觉判断件**，不是可用原型。
