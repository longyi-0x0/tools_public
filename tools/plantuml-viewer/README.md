# PlantUML 看图（`plantuml-viewer`）

壳里打开的一页静态工具：贴一段 `.puml`，把图交给 **PlantUML 官方服务器**渲染后显示。
看图体验是 v2 的重点——放大到能读、把图铺满、把图拿得走；仍然只做看图，不做编辑、不做导出、不做图库。
在线编辑与官方文档在页面顶部的「官网 ↗」（专注模式下随标题一起收起）。方案与验收表见 `docs/design/plantuml-viewer-v2.md`。

```text
tool.json            # id 与版本只从目录名取，这里不写
package.json         # 只为 node 跑 test/ 时按 ESM 解析；不发布
site/                # 发布时整目录拷走，线上就是这几个文件
  index.html         # entry
  viewer.css
  viewer.js          # 状态机、视图状态（缩放/平移/专注）与 DOM
  encoding.js        # UTF-8 → raw DEFLATE → PlantUML 自定义 base64（纯函数）
  examples.js        # 三个内置示例
test/
  encoding.test.mjs  # 编码对拍：请求官方服务器，要 200 + image/svg+xml
README.md            # 不发布
```

## 交互

### 工具条（常驻在预览上方）

| 控件 | 做什么 |
| --- | --- |
| `−` / `＋` | 按当前缩放乘/除 1.25，切到手动缩放；范围 25%–400% |
| 百分比按钮 | 有图时显示当前缩放；点一下按当前模式重算（手动缩放时回到「适应宽度」） |
| 「适应宽度」 | 图宽铺满预览可用宽度（宽图默认落在这里，2089 px 的图不会被压成一条） |
| 「适应页面」 | 整张图塞进视口；小图不放大超过 100% |
| 「100%」 | 图按 1:1 的自然尺寸显示 |
| 「⤢ 专注」/「⤢ 退出专注」 | 页面内专注模式：收起源码栏与标题，图铺满 iframe；再点或按 `Esc` 退出 |
| 「↗ 原图」 | 新标签打开当前 SVG 直链（浏览器开新标签，桌面壳交给系统浏览器）；有地址后可用（成功、失败、超长都保留地址） |
| 「⧉ 复制地址」 | 把当前 SVG 直链写进剪贴板；被浏览器拦下时用 `execCommand` 回落，再不行给一句人话 |

三个模式按钮互斥高亮（`aria-pressed`）；读数行显示「宽 × 高 · 百分比 · 编码 N 字符」。

### 缩放与平移

- **滚轮直接缩放**，不用按 Ctrl/⌘：以指针位置为锚点，一档 ×1.1，25%–400%，120 ms 合并一次；
  指针不在图上或还没有图时不接管滚轮。
- 图放大到超出视口后，可以在图上**按住拖动**平移（`pointer` 事件 + 滚动位置，不越界）；没溢出时不拦，
  保留正常的滚动与选中。
- 缩放只改 `<img>` 的 CSS 宽度，**不重新请求**；换图、切模式、窗口尺寸变化、进出专注模式都会按当前模式重算，
  百分比读数跟着更新。
- 换图不沿用上一张的缩放：模式记着（`localStorage` 只记 `mode`，不记 `scale`），比例按新图的尺寸重算。
  手动缩放下没有可重算的公式，就用新图的「适应宽度」作起点，模式仍是手动。

### 专注模式

按钮进入、按钮或 `Esc` 退出（iframe 里的按键不冒泡到壳，所以退出入口必须有按钮）。进入后 `.top`、源码栏、
操作行、读数行与图下说明都收起，只留工具条、图与必要的状态说明；退出后恢复原版式。专注状态记在 `localStorage`，
重载页面会保持在专注模式。它**不是**浏览器全屏：壳的 iframe 只声明了 `allow="xr-spatial-tracking"`，
桌面壳里页面与壳跨源，`requestFullscreen()` 会被拒，同一个按钮在浏览器和桌面壳里会表现分裂——
所以只做页面内铺满，不申请任何全屏权限。

### 读数与说明

- 成功：`2089 × 612 · 61% · 编码 1276 字符`，图下常驻一行「图里的英文来自官方服务器——PlantUML 报告的问题见图中」。
- 失败 / 超长 / 浏览器太旧：读数变成「没取到尺寸」，缩放控件禁用，失败卡片给「重试」，有地址时还有「在新标签打开这张图」。
- 取图超时（20 秒）时如果屏幕上还有上一张图：不清屏、不锁缩放，只在图下贴一条状态说明，点「渲染」重试；
  首次加载就超时才换成失败卡片。

## 加载方式

`<img src="https://www.plantuml.com/plantuml/svg/<编码>">`，不 `fetch` 图片字节：
跨源图片本来就能显示，也不需要依赖官方服务器的 CORS 头。成功看 `img.onload`，
失败看 `img.onerror`——但 `onload` 不代表图是对的（语法错、编码错都会以图片形态回来）。
所以图下的说明常驻，语法错时用户能知道那是官方服务器画的报错图。

编码（`site/encoding.js`，浏览器与 node 共用同一份）：

1. 源码 → UTF-8 字节；
2. 原生 `CompressionStream("deflate-raw")` 压成 raw DEFLATE（RFC 1951，无 zlib 头尾）；
3. 压出来的字节按 PlantUML 自己的 base64 表 `0-9A-Za-z-_` 编码。

不 vendor 第三方压缩库；浏览器没有 `CompressionStream` 时页面只说「浏览器太旧」，不发请求。

## 为什么没有下载 / 另存为按钮

图是跨源 `<img>`：官方响应是 `image/svg+xml`，**没有 `Content-Disposition`**，跨源链接上的 `download`
属性会被浏览器忽略，点下去只是又打开一次图片；要做真正的下载就得 `fetch` 图片字节再转 `blob:`，
那会依赖官方服务器的 CORS 头（随时可能撤），违背这里“只用 `<img>`”的决定。存档路径是
「↗ 原图」→ 系统浏览器里右键另存为 / `Ctrl+S`，成本更低也少一条失败面。

## 失败面

| 情形 | 页面 |
| --- | --- |
| 正常 | 图 + 「宽 × 高 · 百分比 · 编码 N 字符」；图下常驻一行「图里的英文来自官方服务器——PlantUML 报告的问题见图中」 |
| 源码没写 `@startuml` | 自动补头尾，并显示「已自动补 @startuml/@enduml」 |
| 语法错 | 照常显示官方那张 400 的报错 SVG（服务端 400 但 `Content-Type` 仍是 `image/svg+xml`），图下那行说明指过去 |
| 地址 > 7000 字符 | 前端先算长度，不发请求，直接说「这段图太大……约 N 字符」；缩放控件禁用 |
| 断网 / 被拒 / 服务器忙 | 失败卡片：一句人话 + 「重试」+ 「在新标签打开这张图」（`<img>` 拿不到状态码，所以不承诺原因） |
| 取图超时（20 秒） | 有旧图：保留旧图与缩放，图下状态行提示重试；无旧图：失败卡片 |
| 浏览器没有 `CompressionStream` | 失败卡片，说明换浏览器；同样不发请求 |

源码、视图模式、专注状态各存一个 `localStorage` 键（`toolbox.plantuml-viewer.source` / `.mode` / `.focus`），
重载页面能恢复；不存缩放比例。

## 不做什么

真全屏（理由见上）、导出 PNG/SVG 下载、另存为按钮（理由见上）、多标签/图库、双击放大、分栏拖拽、
语法高亮、自定义服务器地址；不引第三方库（`site/vendor/` 不存在），`tool.json` 的 `capabilities` 保持 `[]`。

## 自测

```powershell
node tools/plantuml-viewer/test/encoding.test.mjs      # 需要联网
node --check site/viewer.js                            # 语法
```

对拍只认「服务端解得开」：`200` + `image/svg+xml` + 正文不含
`This URL does not look like DEFLATE data`；不逐字符比编码串（DEFLATE 实现不保证同字节）。
请求必须带浏览器 UA，否则官方直接 403。缩放、平移、专注模式这些交互只能在真实浏览器里验收。
